未來如何新增更多教材到這個網站？

本站具備高度擴充架構，未來您可以源源不絕地將講義或試卷交給 AI 助理轉換，只需三步即可發布：

1

交由 AI 自動轉譯

上傳 Word、PDF 或考卷圖片，對 AI 助理說「幫我做成報讀HTML」，即可產出符合特教規格的朗讀單頁。

2

放入 materials 目錄

將新產出的 HTML 存入 materials/ 資料夾，並可透過 scripts/update_catalog.js 自動更新目錄。

3

同步 GitHub 自動上線

推送到 GitHub 倉庫後，GitHub Pages 會自動部署更新，學生掃描首頁 QR Code 即可同步讀取！
