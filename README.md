# 🎧 特教無障礙語音報讀學習網 (Voice Reading Hub)

這是一個專為特教、資源班與視障學生打造的**無障礙語音報讀學習網**。支援平板/手機相機掃碼進入、單句點讀螢光高亮、自訂語速與繁體中文原生語音朗讀。

- 🌐 **網站網址**：https://ting03040929-cmyk.github.io/voice-reading-hub/

---

## 🌟 網站特色

1. **平板友善、免下載**：學生拿平板相機掃描 QR Code 即可直接進入練習，不需登入或安裝 App。
2. **單句點讀與高亮**：點擊題目或說明的任何一句話，系統只會朗讀該句並搭配螢光高亮，不強迫聽完整大段。
3. **整題循序播放**：提供「唸題目 / 停止」按鈕，可逐題循序朗讀觀念引導與題幹。
4. **數學 LaTeX 自動優化**：分數、負號、線段、絕對值、平方等皆由語音轉換器自動優化為正確繁體發音。
5. **國文科專用聽讀練習卡片模式**：手機直向卡片版面、加大按鈕觸控、題目與各選項獨立分開點讀、微軟真人語音（臺灣曉臻）+ 原生備援雙引擎、底部懸浮播放狀態面板。
6. **高度模組化與擴充性**：未來所有新教材只需放入 `materials/` 資料夾即可一鍵同步發布。

## 👩‍🏫 教師如何新增更多教材？

當您有新的試卷或講義需要轉成報讀網頁時：

1. **請 AI 助理生成**：
   上傳考卷或貼上文字，並對 AI 說：
   ```text
   幫我做成報讀HTML
   ```
2. **存入教材目錄**：
   將產出的 HTML 檔放入 `materials/` 資料夾（例如 `materials/chinese-l1.html`）。
3. **更新目錄**：
   執行下方指令，系統會自動辨識標題與題數並更新首頁清單：
   ```bash
   node scripts/update_catalog.js
   ```
4. **同步到 GitHub**：
   ```bash
   git add .
   git commit -m "Add new reading material"
   git push
   ```
   GitHub Pages 會在 1~2 分鐘內自動更新上線！
